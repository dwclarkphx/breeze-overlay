# companion-module-breeze-overlay has moved

The Bitfocus Companion module for Breeze Overlay now lives in its own
repository, maintained under the Bitfocus organisation:

**<https://github.com/bitfocus/companion-module-breeze-overlay>**

Source, issues and the operator help all live there. Once the module is
published in the Bitfocus module directory, Companion installs it through its
own module manager — search for **Breeze Overlay** under Modules — so nothing
needs to be built from this repository.

The module is MIT-licensed, separately from Breeze Overlay itself.
