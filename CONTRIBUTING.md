# Contributing

Thanks for your interest in Breeze Overlay. The project lives at
<https://github.com/dwclarkphx/breeze-overlay> — issues go to
[the tracker](https://github.com/dwclarkphx/breeze-overlay/issues), questions to
[Discussions](https://github.com/dwclarkphx/breeze-overlay/discussions).

## Bug reports and feature requests: yes, please

The best way to contribute is a well-written issue. Use the issue templates — a bug report with exact reproduction steps, your template/project JSON, and console errors will usually get fixed quickly; a vague one usually can't be fixed at all.

Before filing, check existing open and closed issues for duplicates.

## Pull requests: not accepted at this time

This project is maintained by a single developer and code changes are written by the maintainer. Unsolicited PRs will be closed — but the underlying idea is welcome as an issue. If a fix is obvious to you, describing it in the issue ("the problem is X in file Y") is helpful and will be credited.
